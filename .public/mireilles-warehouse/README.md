# Mireille's warehouse

This folder is where Mireille shares things she has built, so Marc can see what she wants in CRAFT next. First time on a new computer? Do [SETUP-WINDOWS.md](SETUP-WINDOWS.md) once.

## Add an idea

1. In VS Code, click the branch name in the bottom-left corner, choose **Create new branch**, and name it `mireille/<idea>`, for example `mireille/budget-dashboard`.
2. In this folder, make one new folder per idea, named with the month and a few words, for example `2026-11-budget-dashboard`.
3. Put your files in it, plus a file called `notes.md` with a few lines: what it is and what you'd like CRAFT to do.
4. Open **Source Control** (the branching icon on the left). Type a short message, such as "Budget dashboard idea", and press **Commit**. If it asks to stage all changes, choose **Yes**.
5. Press **Publish Branch**.

## Put it on main

1. On GitHub, open the CRAFT repository. A yellow banner shows your branch: press **Compare & pull request**, then **Create pull request**.
2. Press **Squash and merge**, then **Confirm**. There are no checks to wait for.
3. Back in VS Code, click the branch name in the bottom-left and switch to `main`.

## Everything here is public

This folder is visible to anyone on the internet. Never add passwords, keys, agency documents, people's details or anything private.
